# Data directory

Store structured learning content here as JSON or other static data files.

Suggested future files:
- `subjects.json` — bilingual subject metadata.
- `formulas.json` — formula records with topic, notation, explanation and references.
- `exercises.json` — exercises, difficulty, hints and worked solutions.
- `glossary.json` — Vietnamese / English mathematical terminology.

Keep content separate from presentation so that the same data can later power search, filters and learning tools.
